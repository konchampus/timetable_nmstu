# Монополия v2 — телефон, классические правила и дополнительные режимы

Локальная реализация. Production, реальные аккаунты/балансы и серверные сервисы этой задачей не изменялись. Предыдущую мобильную компоновку пользователь отклонил; отсутствие overflow не считалось удобством.

## Имена игроков из Telegram

По умолчанию лобби подставляет имя из авторизованного /me; вручную заполнять его не нужно. Создание, вход по коду и публичный вход отправляют use_telegram_name=true, сервер выбирает User.name, ранее полученное из проверенного initData. Клиент не задаёт чужое «подтверждённое» имя. Можно явно написать свой ник только для этой партии (не меняет Telegram-профиль); уже начатые партии и reconnect сохраняют прежнее имя. До30символов, нормализация пробелов, пустой профиль — «Игрок».

Телефонная книга и локальные имена чужих контактов боту/Mini App недоступны. Новые разрешения, запрос номера телефона и чтение контактов не добавлены. Повторы старых UUID-команд совместимы: default нового флага исключён из legacy fingerprint, явный Telegram-режим имеет отдельный fingerprint.

## Телефон

Большое native dialog/fullscreen сохраняется. Вместо длинной desktop-колонки — пять разделов: **Поле, Активы, Сделки, Чат, Меню**. Header и chips игроков компактны; прокручивается только выбранная задача. На Поле — обзор и крупное следующее действие, а не мелкие кнопки на клетках. Крупное поле и карточка актива открываются отдельным native dialog; Escape возвращает в партию. Закрытие окна не сдаёт игрока.

Активы имеют читаемый список с собственником/ценой, фильтрами и управлением. Для28 покупаемых активов — **28 разных оригинальных SVG-сюжетов**, а не перекрашенная иконка группы: лавка/пруд, ателье/джинсовая фабрика/подиум, пекарня/кофейня/ресторан,4аэропорта и т.д. Чужие растровые assets не копировались. Цвет акцента и фишки сохраняется.

Кубики3D с SVG-гранями показывают только серверный результат: падение/вращение/2отскока780мс, без задержки POST; reduced-motion статичен. Ролл маркер не меняется от чата/reconnect. Доступность оценивается на360×740 и390×844, а не только по ширине.

## Официальная основа

Основная редакция — **Hasbro C1009 F22, 0622C1009780, ©2021**: [официальная страница инструкции](<https://instructions.hasbro.com/en-us/instruction/monopoly-board-game-for-ages-8-for-2-6-players-includes-8-tokens-tokens-may-vary>). Старые чисто извлечённые официальные PDF [Rev2](<https://www.hasbro.com/common/instruct/monins.pdf>) и [Deluxe](<https://www.hasbro.com/common/instruct/deluxemonopoly.pdf>) использованы для проверки спорных OCR-фрагментов, не для смешивания несовместимых вариантов. [Досье источников](<.tasks/rules-v2-sources.md>) отмечает различия редакций.

Классическая экономика:1500 каждому,200 за проход/остановку на Старте, стоянка без банка налогов, налоги200/100. Одна стартовая кость определяет первого игрока; при равенстве перебрасывают только претенденты. Движение —2кости, дубли/три дубля, тюрьма3попытки/50/карта. Случайность выбирает сервер, будущие колоды не выдаются клиенту.

Отказ от покупки — обязательный аукцион, участвовать может и отказавшийся. Полная группа удваивает базовую ренту незастроенного незаложенного участка, даже если соседний участок группы заложен. Заложенный актив аренду не приносит.4аэропорта используют механику железных дорог,2коммунальных предприятия — utilities.

Строительство, продажа зданий, залоги и сделки доступны **вне своего хода и в тюрьме**, но не во время активного аукциона. Строить/продавать равномерно, нельзя строить при залоге в группе. Банк32дома/12отелей; при размене отеля нужны4свободных дома. Если их нет, можно продать все здания группы за половину стоимости. Последнее конкурируемое здание — отдельный аукцион с выбором легального участка участника; здание и деньги переходят атомарно.

Сделки: деньги, участки без зданий во всей цветовой группе, карты выхода из обеих колод. **Заложенные участки разрешены**: получатель либо платит банку10% залоговой суммы и сохраняет залог, либо сразу выкупает за principal+10%; поздний выкуп требует principal+10% ещё раз. Предложение содержит выбранный вариант, обе стороны видят затраты. Условия/наличие денег/карт/собственность перепроверяются при принятии. Должник может продавать активы/карты другому игроку для погашения долга, а не только закладывать. Предложение третьих игроков не блокирует текущий ход.

Банкротство по долгу отличается от добровольной сдачи: нельзя объявить себя неплатёжеспособным при наличии достаточной ликвидационной стоимости. Наследование залога сейчас выбирает сохранение залога с10% процентов; наследник затем может выкупить с дополнительными10% — явная онлайн-адаптация. Активы должника кредитору, при долге банку — в очередь аукционов; карты/полцены зданий/проценты учитываются.

## Режимы (выбираются до создания комнаты)

| Режим | Окончание и отличия |
|---|---|
| Классика | До последнего участника; **без5/15-минутного принудительного банкротства** |
|20 /40 /60минут | Явно домашние онлайн-пресеты: обычный старт без раздачи deeds, затем победитель по капиталу; ничья не теряется |
| Дружеская | Классическая экономика без таймера + исполняемые договоры освобождения от аренды |

Timed-пресеты **не называются точной официальной TIME LIMIT GAME**: в старых инструкциях иной старт с2оплачиваемыми deeds. Здесь стоимость = наличные + номинал незаложенных участков + половина номинала заложенных + полная цена зданий (отель включает4заменённых дома). При истечении сначала разрешаются долг, покупка, карточная цепочка и аукционы; необязательные предложения сделок закрываются. Окончание проверяется сервером при команде, не отдельным scheduler; если все ушли, партия ждёт возвращения. Время сети не создаёт банкротства.

## Договоры — пользователь выбрал будущие обязательства

В **friendly** владелец предлагает выбранному игроку не брать аренду на конкретных своих участках на1–12 **общих завершённых ходов**. Дубль не увеличивает счётчик; это не число кругов и не только ходы получателя. Получатель платит владельцу согласованную сумму **сразу при принятии**, не при предложении. Нет займа, будущего долга или доверия к тексту чата.

Сервер проверяет режим, участников, владение, срок, деньги и пересечения заново. До8активных договоров; одинаковые владелец/получатель/участок не перекрываются. Льгота заканчивается при turn_number>=expires_turn, смене владельца или выходе участника; передача одного участка не удаляет остальные условия. Возврата платы нет, принятый договор односторонне не отзывается. Эти условия показываются перед согласием. В классике такие льготы/займы запрещены.

## Сдаться

Меню → «Сдаться в этой партии» → отдельное подтверждение. Работает в любой момент, включая чужой ход/долг/роль аукциониста или лидирующего покупателя. Друга-получателя выбрать нельзя: при собственном долге — текущему кредитору, иначе банку в очередь аукционов. Ставка выбывшего лидера отменяется и торги перезапускаются для оставшихся — это онлайн-политика выхода, не буквальное правило настолки. Обычный крестик лишь закрывает представление, не прекращает партию.

## Сеть, сохранение и атомарность

PostgreSQL JSONB Room, User→Room FOR UPDATE, account_generation fencing, optimistic game version и UUID journal: состояние, event_version и ответ команды в одной транзакции. При повторе ключа — исходный результат; новый payload со старым ключом отклоняется. После подтверждённого POST интерфейс освобождается сразу, read-only сверка не держит кнопку busy. Неопределённый ответ сохраняет исходную команду для безопасного повтора; чужой/старый ответ не воскрешает закрытую комнату и не откатывает чат.

Long poll /api/monopoly/rooms/{id}/events?cursor=N: интервал обнаружения300мс, ожидание18с, без удержания read-транзакции/row locks в паузах. Durable event_version отдельно от игровых версий — чат не инвалидирует ход. Live auth/membership и generation перепроверяются; лимиты64held/worker,2/user/worker,60events/min через БД, общийAPI180/min. При ошибках read-only fallback с backoff до15с, без повторных мутаций/hot loop; скрытая вкладка отменяет подписку.300мс — не production SLA, реальная сеть/БД добавляют задержку.

Партии переживают перезапуск. Удаление аккаунта завершает начатую партию без победителя и анонимизирует историю; lobby передаёт хоста. Лимит8активных комнат не запрещает reconnect. Чат80сообщений/500символов/1сек, журнал100событий; личные Telegram ID и будущие карты не выдаются. Закрытые80-битные коды не попадают в публичный поиск.

## Отличия от настольной и границы проверки

Тематическое поле вместо лицензированных названий; автоматическое взыскание аренды; ставки по очереди с окончательным пасом в рамках аукциона; явный запуск аукциона последнего здания; автоматическое keep+10% при наследовании залога; добровольная сдача/перезапуск ставки выбывшего. Эти цифровые соглашения должны быть обозначены, а не названы дословной копией Hasbro. Friendly и timed — отдельные домашние режимы.

[Проверки](<MONOPOLY_VERIFICATION.md>) разделяют engine/API tests, настоящие DOM-сценарии на synthetic ui-lab и непроверенную реальную инфраструктуру. До релиза нужны staging PostgreSQL,2workers/2Telegram-аккаунта, race/replay/delete checks и WebView с клавиатурой/safearea. Никакой production-выкладки или установки ПО без отдельного разрешения. Релиз backend+web совместный; events timeout proxy>25с; миграция0005наstaging послеbackup; destructive downgrade непустых комнат запрещён.
