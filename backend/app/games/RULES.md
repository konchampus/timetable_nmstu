# Правила v1 (rules_version=1)

Только развлекательные очки, без денежной стоимости. RNG — secrets.SystemRandom. Все множители — **общая выплата**, включая возврат ставки; чистая прибыль = выплата − ставка. Выплата вычисляется точной рациональной арифметикой, затем округляется вниз до целого. Ставки 10–500; рыбалка бесплатная, bet=0. Например, 10 × 1.9 = 19 (прибыль 9). Максимумы ниже для ставки 500.

## Мгновенные игры
- Слоты: три независимых равновероятных символа cherry/lemon/bell/diamond/seven (125 исходов). Три одинаковых: 5/7/10/15/25 соответственно, каждый с вероятностью 1/125. Ровно пара: ×1, 60/125. Остальные: ×0, 60/125. Максимум 12500, RTP 122/125.
- Кости: равновероятные 1–6; low = 1–3, high = 4–6. Угаданный диапазон ×1.9 (1/2), иначе 0. Максимум 950.
- Дартс: зоны 0/5/10/20/25/50, каждая 1/6. Выплаты 0/0/0/1/2/3. Максимум 1500.
- Боулинг: 0–10 кеглей равновероятны (1/11). 0–6: 0, 7–8: ×1, 9: ×2, 10: ×7. Максимум 3500.
- Баскетбол: value 1–5 равновероятно; 4–5 попадание (2/5), ×2.25; 1–3 промах, 0. Максимум 1125.
- Футбол: value 1–5 равновероятно; 3–5 гол (3/5), ×1.5; 1–2 промах, 0. Максимум 750.
- Монетка: heads/tails равновероятны, угаданный исход ×1.9. Максимум 950.
- Европейская рулетка: равновероятные 0–36. number:N (N=0..36) ×36, 1/37. red/black/even/odd ×2, 18/37. Ноль зелёный, проигрыш для обоих цветов и чётностей. Красные: 1,3,5,7,9,12,14,16,18,19,21,23,25,27,30,32,34,36. Максимум 18000.
- Колесо: 10 равновероятных секторов [0,0,0,0.5,0.5,1,1,1.5,2,3]. Суммарные вероятности: 0:30%, 0.5:20%, 1:20%, 1.5:10%, 2:10%, 3:10%. Максимум 1500, RTP 0.95.

## Блэкджек
Одна перемешанная колода 52 карт без джокеров, без возврата, новая для каждого раунда; карты AS..KS, AH..KH, AD..KD, AC..KC. Туз 1/11, лица 10; дилер берёт до 17, останавливается на мягких 17. Два начальных туза/десятка дают natural: ×2.5; встречные natural — возврат ×1. Обычная победа ×2, равенство ×1, проигрыш ×0. Split/double/страховки нет. Natural определяется сразу; после hit 21 автоматически stand. Колода и закрытая карта не передаются в активном раунде. Вероятность каждой следующей карты равна 1 / числу оставшихся карт; начального natural = 2×4×16/(52×51). Максимум 1250.

## Сапёр
25 клеток, индексы 0–24, 1–10 мин, равновероятная выборка без возвращения; первая клетка не защищена. После k безопасных открытий множитель = floor(10000 × 0.97 × C(25,k)/C(25−m,k))/10000. Выплата = floor(bet × этот множитель). До первого открытия cashout возвращает ставку ×1. После всех безопасных клеток выплата автоматическая. Вероятность пережить k клеток = C(25−m,k)/C(25,k); следующая безопасная клетка: (25−m−k)/(25−k). values — числа соседних мин только для уже открытых безопасных клеток; позиции мин скрыты до завершения. Максимум при m=10: floor(500×0.97×C(25,10)) = 1585348600.

## Рыбалка
Один активный заброс. Удочка уровней 1–5; ожидание 15/12/10/8/6 секунд серверного времени. Цена перехода на следующий уровень: 250/750/1500/3000; максимум 5. Вероятности common/uncommon/rare/epic/legendary по уровням (%): [65,23,9,2,1], [57,26,12,4,1], [49,28,15,6,2], [40,30,18,9,3], [30,30,22,13,5]. В каждой редкости один вид: Плотва/Карась/Щука/Сом/Золотая рыба. Фиксированные стоимости 10/25/60/150/400. Вес равновероятный целый грамм в диапазонах 100–500/300–1200/1000–4000/3000–12000/500–2000, API отдаёт килограммы. Результат определён при забросе, хранится скрыто до collect; на время ожидания результат недоступен через любые DTO. Продажа всех непроданных рыб атомарна; sold = количество рыб, balance = итоговый баланс. Коллекция видов и рекорд веса остаются после продажи.

## Экономика, сроки и восстановление
Стартовый бонус 1000 только при первом создании кошелька; ежедневный 200 раз в календарный день Asia/Yekaterinburg. Все изменения с журналом и идемпотентной записью в той же транзакции. Один key уникален для пользователя среди всех операций; отпечаток включает endpoint и все параметры, включая version; другое тело с тем же key — 409. Подтверждённый повтор возвращает исходный JSON, включая прежний баланс. Сетевой сбой: повторить тот же key и тело.

Раунды хранятся в PostgreSQL. Закрытие WebView не завершает и не отменяет их. Через 24 часа блэкджек автоматически доигрывается stand, сапёр автоматически cashout (без открытий — полный возврат). Это ленивое завершение при следующем чтении/операции владельца; payout начисляется атомарно, status=expired, результат содержит timeout=true. Рыбалка не истекает и ожидает collect без потери улова. Активный раунд одного типа запрещён частичным уникальным индексом. В каждой мутации порядок блокировок User → Wallet → GameRound → Inventory; активность User, поколение аккаунта и исходная AuthSession (digest/owner/expiry) повторно проверяются под блокировкой через общий lock_authenticated_user; это относится и к защищённым чтениям и повторам ключа. Минимальный интервал новых мутаций 250 мс, идемпотентные повторы не ограничены. Транзакционные lock_timeout 3 секунды / statement_timeout 10 секунд; deadlock/serialization получают до трёх ограниченных повторов.

Рейтинг только при Settings.leaderboard_visible=true и непустом nickname. Wealth = баланс + сумма фиксированных стоимостей непроданных рыб. Fishing = число различных пойманных видов ×100000 + рекорд веса в граммах; максимум веса 12000, поэтому коллекция приоритетнее. Равные score получают одинаковую dense_rank; показ top100 стабилизирован внутренним user_id, который никогда не публикуется. self.rank=null без согласия, self.score доступен только владельцу. Согласие проверяется на каждом запросе; нет кэша публичного рейтинга.
