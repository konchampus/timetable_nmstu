# Точка восстановления · 16 ноября 2026

## Состояние и ограничения

Разработка продолжена из существующих исходников после сбоя предыдущей сессии. Проект не переписывался с нуля, пользовательские учебные материалы вне этой папки не менялись. В рабочей папке не обнаружен Git-репозиторий: историю изменений и прежних запусков по Git восстановить нельзя. История исходной сессии через session storage также недоступна; использованы предоставленная пользователем выдержка и реальные файлы.

В этой сессии **не запускались тесты, сборка, приложение, миграции, установка зависимостей или runtime/security/browser проверки**. Production, SSH, DNS, BotFather и старый бот не затрагивались. Переключение production требует отдельного согласования точного cutover/rollback. Токены и пароли в чат не нужны.

Наличие кода не является доказательством работоспособности, отсутствия утечек или качества игрового опыта. Не выдавать эту точку за прошедший приёмку публичный релиз.

## Что уже существовало и сохранено

- Python FastAPI/aiogram, отдельные API/bot/worker, PostgreSQL/SQLAlchemy, модели, первая Alembic-миграция, адаптер реального источника, пользовательские настройки и очередь.
- Telegram-авторизация, owner checks, account generation, optimistic version, DB locks, игровой журнал и idempotency, сохранённые раунды.
- Mini App: Сегодня / Неделя / Поиск / Игры / Профиль, заметки/ДЗ, избранное и история просмотров, общие уведомления.
- Все 12 игровых модулей и конфигурации правил: slots, fishing, dice, darts, bowling, basketball, football, coin, roulette, blackjack, mines, wheel. Серверные результаты, Three.js-сцены, Web Audio, DOM fallback, reduced motion и экономичный режим. Состав не сокращён.
- [npm lock](<frontend/package-lock.json>), [Python hash-lock](<backend/requirements.lock>) и локальное Python-окружение уже находились на диске. Они не создавались и не устанавливались заново в этой сессии; прежние документы об отсутствии locks были устаревшими.

## Изменения этой сессии

### Сервер и безопасность

- [Очередь](<backend/app/notifications.py>): claim/recovery/finish используют PostgreSQL clock для lease. Завершение требует живого токена владения; поздний Forbidden ограничен тем же поколением аккаунта и активной отправкой, чтобы не блокировать заново созданный аккаунт.
- [Источник](<backend/app/timetable.py>): перед публикацией поискового кэша/каталога проверяется захваченный lease под DB lock. Старый медленный ответ не публикуется после потери владения. Входные элементы поиска проверяются как объекты; порядок/дубли ссылок нормализуются до сравнения занятий.
- [Авторизация](<backend/app/security.py>): существующее разрешение на сообщения учитывается только из подписанного Telegram user.allows_write_to_pm. Само разрешение автоматически не запрашивается и не выдаётся.
- [API заметок](<backend/app/api.py>): серверный поиск также по предмету; батчевое чтение только указанных публичных снимков для статуса связанной пары, без сетевого I/O под owner lock.
- [Игровой сервис](<backend/app/games/service.py>) и [router](<backend/app/games/router.py>): приватный постраничный GET /api/games/ledger. Только разрешённые поля, без owner ID и raw idempotency/event keys.
- [Backend Dockerfile](<backend/Dockerfile>) использует существующий hash-lock с --require-hashes; [.dockerignore](<.dockerignore>) исключает также вложенные env, keys, logs, secrets и backups. Docker не запускался.

### Mini App

- [Заметки](<frontend/src/components/Notes.tsx>): поиск по всем записям через API, фильтр типа, пагинация, защита от устаревших ответов. Неизвестный результат сохранения сохраняет неизменный payload до повтора; редактор не меняет поля этого запроса. Данные не отправляются аналитике и не пишутся в browser storage.
- У заметки сохраняется исходное расписание, а не текущая домашняя группа. При исчезновении пары отображается предупреждение, запись остаётся; если свежего снимка или старой связи нет — честное состояние unknown.
- [Сегодня](<frontend/src/components/Timetable.tsx>): следующая начинающаяся пара во время текущей, параллельные варианты, прошедшая и оставшаяся части перерыва. Время остаётся Asia/Yekaterinburg.
- [Игры](<frontend/src/games/Games.tsx>): ссылки /game из бота открывают разрешённую конкретную игру с корректным первоначальным выбором, без автоматической ставки; возврат ставки имеет нейтральный звук.
- [3D](<frontend/src/games/GameScene.tsx>): анимация раздачи промежуточных ходов, появление открытых клеток и терминальных мин, траектория баскетбольного мяча через кольцо либо в сторону по серверному исходу. Fallback-кнопка остаётся доступной через role=group.
- [Журнал](<frontend/src/games/Ledger.tsx>): история начислений/списаний, balance_after, пагинация и восстановление загрузки.
- [Профиль](<frontend/src/components/Profile.tsx>): явная кнопка системного запроса права на личные сообщения. Без нажатия permission prompt не вызывается; категории уведомлений включаются отдельно, /start остаётся способом начать/возобновить диалог.

## Миграция — не применена

[0002_note_source](<backend/alembic/versions/0002_note_source.py>) добавляет nullable source_entity к заметкам. Первая миграция не переписана, старые заметки/тексты не удаляются; старое происхождение не угадывается. Новый backend требует обновлённой схемы. Применение upgrade и проверка отката — только на отдельно разрешённом этапе, сначала на выделенной локальной БД.

Контракт новых DTO/API записан в [CONTRACT](<CONTRACT.md>). Выполнение миграции в production этим документом не разрешается.

## Что не подтверждено и нужно перед выпуском

1. Разрешённые сборка TypeScript/Vite, Python/import/schema checks, установка и аудит locks на целевой платформе; digest образов. Существование locks само по себе не гарантирует их совместимость и безопасность.
2. Разрешённые миграции и восстановление backup на отдельной БД; сверка metadata с Alembic head.
3. Разрешённые функциональные, многопроцессные и security проверки, включая late worker, потерю HTTP-ответа, удаление/recreate, доступ двух пользователей, игры и журнал. Полная матрица — [VERIFICATION](<VERIFICATION.md>).
4. Живая приёмка всех 12 игр, звука, 3D, GPU cleanup, Android/iOS/Desktop/Web Telegram, safe areas, доступности и reduced motion. Плавность и увлекательность не оценены по исходникам.
5. Название, домен/HTTPS, новый токен через защищённое хранилище, инвентаризация vices-prod, точная заменяемая служба, backup и отдельное подтверждение cutover.

Никаких команд приёмки автоматически после восстановления не запускать: запрет пользователя на тесты остаётся в силе.
